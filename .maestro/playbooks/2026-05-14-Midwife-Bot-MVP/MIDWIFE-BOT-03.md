- [ ] Implement `api/routes/webhook.py` — the WhatsApp webhook handler. It must handle: `GET /webhook` for Meta's hub verification challenge (check `hub.verify_token` against `Settings.WHATSAPP_VERIFY_TOKEN`, return `hub.challenge`); `POST /webhook` for inbound messages with HMAC-SHA256 signature verification (header `X-Hub-Signature-256`; return 200 immediately to avoid Meta retry, then process async). The POST handler dispatches to `_handle_inbound(payload: MessagePayload)` as a background task. Write `tests/api/test_webhook.py` with at least 5 test cases using `httpx.AsyncClient`: GET verify with correct token returns challenge, GET verify with wrong token returns 403, POST with valid signature queues background task and returns 200 immediately, POST with invalid signature returns 401, POST with non-text message (image) returns 200 without queuing any task. Run `pytest tests/api/test_webhook.py` and confirm all pass.

- [ ] Implement `_handle_inbound(payload: MessagePayload)` in `api/routes/webhook.py` (the background task). It must implement the full inbound flow from the plan: (1) look up conversation by phone using `conversation.get_by_phone()`, (2) if no conversation found, check for token in message text using `conversation.get_by_token()` — if token found, send consent prompt via `whatsapp.send_message()`, transition state to `AWAITING_CONSENT`; (3) if state is `AWAITING_CONSENT` and message is "YES" (case-insensitive), store consent record (message id + timestamp + verbatim), transition to `ACTIVE`; (4) if state is `ACTIVE`, run the full triage→RAG→draft flow and push to PWA inbox via Firestore; (5) log every event via `audit.log_event()`. Write `tests/api/test_webhook_handler.py` with at least 6 test cases (all mocked): unknown phone with no token → no action taken, unknown phone with valid token → consent prompt sent + state set to AWAITING_CONSENT, AWAITING_CONSENT + "YES" → state set to ACTIVE + consent stored, AWAITING_CONSENT + other message → ignored, ACTIVE + normal message → draft created in Firestore, ACTIVE + HIGH urgency message → no draft, urgent flag set. Run `pytest tests/api/test_webhook_handler.py` and confirm all pass.
